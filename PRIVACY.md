# Политика обработки данных приложения «Скидка найдена»

Политика размещена по публичной ссылке https://github.com/maxhermesov-hue/skidka-naidena-privacy/blob/main/PRIVACY.md и доступна из раздела приложения «О приложении → Данные и конфиденциальность».

Оператор приложения — **Борисов Максим Викторович**, физическое лицо. Вопросы об обработке данных, запросы на доступ или удаление, а также обращения в поддержку направляйте на **skidkanaydena@gmail.com**. Не отправляйте пароли, коды доступа и данные других людей.

## 2. Данные и цели обработки

- **Идентификатор установки.** При первом использовании приложение создаёт случайный UUIDv4 и хранит его в приватной памяти устройства. Для учёта голосов («огоньков»), показа личного состояния голоса и учёта запусков оно передаёт UUID нашему серверу по HTTPS. На сервере из UUID с секретным ключом вычисляется псевдонимный HMAC-хеш; исходный UUID в таблицы голосов и запусков не записывается.
- **Голоса.** Сервер хранит ID публикации, псевдонимный хеш установки и время голоса. В публичной ленте показывается суммарное число огоньков, а состояние голоса конкретной установки запрашивается отдельно. Голос можно снять у отдельной публикации.
- **Учёт запусков.** Сервер хранит псевдонимный хеш установки, день по московскому времени и время первого учтённого запуска за день. Это используется для внутренней агрегированной статистики аудитории, не для показа другим пользователям.
- **Сетевые данные и защита.** Сервер получает IP-адрес соединения для обработки запроса. Для ограничений частоты голосов и запусков используются HMAC-хеши IP и краткоживущие служебные счётчики. Прямой IP не записывается в таблицы голосов и запусков приложения. Сетевые провайдеры, серверная инфраструктура и открываемые вами внешние сайты могут обрабатывать IP по собственным правилам.
- **Локальные файлы.** На устройстве могут храниться ранее загруженные публикации, изображения и состояние голосов для быстрого показа и временной работы без сети. Идентификатор установки хранится отдельно в приватных настройках приложения.
- **Поисковые запросы.** Когда вы вводите слова в поиске, приложение передаёт запрос на наш сервер по HTTPS для поиска среди сохранённых публикаций. Запрос не сохраняется в таблицы базы приложения и не передаётся вместе с ID установки; при обработке сетевого соединения сервер получает IP, как и для других запросов.
- **Обращение в поддержку — только по вашему действию.** Функция «Сообщить об ошибке» открывает черновик письма в выбранной почтовой программе. В нём может быть введённое вами описание, необязательная ссылка на пост MAX и версии приложения/Android. Приложение не отправляет письмо самостоятельно и не прикладывает ID установки, логи или фотографии автоматически. Если вы отправите письмо, оператор получит ваш адрес отправителя, текст и вложения, которые вы добавите сами.

Обработка идентификатора и голосов необходима для функций, которые пользователь вызывает в приложении; ограничения по IP — для защиты доступности и целостности сервиса; учёт запусков — для оценки работы приложения. Отправка письма — отдельное действие пользователя. Приложение не содержит стороннего SDK рекламы или автоматической отправки диагностических отчётов. Если применимое право требует отдельного согласия для конкретной обработки, оператор обязан обеспечить его до такой обработки; эта политика не заменяет согласие.

## 3. Сроки хранения

- UUID находится на устройстве, пока пользователь не удалит данные этой установки в приложении, не очистит данные приложения в Android или не удалит приложение.
- Голоса и их псевдонимные хеши хранятся до удаления пользователем данных установки через приложение или прекращения работы сервиса. Скрытие публикации из ленты не удаляет её голоса. Автоматического календарного срока удаления голосов сейчас нет.
- Учтённые запуски хранятся в скользящем окне примерно 35 календарных дней; строки за пределами окна удаляются при следующем штатном обслуживании базы. Если обслуживание временно не работает, удаление произойдёт после его восстановления.
- Служебные события ограничения голосов старше 60 секунд удаляются при запуске сервера или при очередном голосовании; дневные агрегированные счётчики сетевого ограничения запусков — при следующем обслуживании в новый день. Сетевые счётчики могут относиться к нескольким пользователям одного IP и не сопоставляются с отдельной установкой.
- Кэш ленты не используется спустя 30 дней с момента сохранения; файл может сохраняться до перезаписи, явного удаления данных, очистки данных приложения в Android или удаления приложения. Кэш изображений ограничен общим объёмом и удаляется по мере вытеснения.
- Письма поддержки хранятся в почтовом ящике до ручного удаления оператором либо удовлетворения запроса отправителя при отсутствии обязательства хранения. Автоматический фиксированный срок удаления переписки не настроен. Сроки хранения у почтовых провайдеров могут отличаться.

## 4. Как удалить данные

В приложении откройте **«О приложении → Данные и конфиденциальность → Удалить данные установки»** и подтвердите действие. Приложение направит серверу запрос с ID этой установки. После подтверждённого ответа сервер атомарно удалит её голоса и учтённые запуски, скорректирует общие счётчики огоньков и удалит события ограничения голосов, связанные с этим ID. Приложение удалит свой локальный ID, кэш ленты и изображений. Если сеть или сервер не подтвердили операцию, локальный ID сохраняется для повторной попытки. При неудаче очистки локальной памяти приложение сообщит об этом отдельно. Действие необратимо; при следующем использовании будет создан новый ID.

Дневные ограничения, рассчитанные по общему IP, не удаляются по одному ID установки: они автоматически удаляются при штатном обслуживании в следующий день. Отправленные вами письма не удаляются этим действием; для удаления переписки напишите на адрес поддержки с адреса отправителя. Простое удаление приложения с телефона **не удаляет уже сохранённые серверные голоса** — используйте кнопку до удаления приложения или обратитесь в поддержку.

## 5. Внешние переходы и безопасность

Лента основана на публикациях нашего канала MAX. По вашему нажатию приложение может открыть исходный пост, страницу продавца либо партнёрскую ссылку во внешнем приложении или браузере. После перехода обработка данных регулируется документами соответствующего сайта или приложения. Отдельные публикации содержат рекламные пометки; наличие и цена товара, промокод и условия зависят от продавца. Письмо в поддержку обрабатывается также почтовым сервисом отправителя и получателя.

Связь с сервером приложения осуществляется по HTTPS. На сервере вместо исходного UUID в таблицах голосов и запусков используется хеш с секретным ключом. Доступ к серверным данным ограничен; абсолютную безопасность и анонимность это не гарантирует. При изменении функций приложения или обработки данных политика будет обновлена по этой же ссылке: https://github.com/maxhermesov-hue/skidka-naidena-privacy/blob/main/PRIVACY.md
